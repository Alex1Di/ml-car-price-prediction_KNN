# Прогнозирование цены автомобиля (KNN)

Модель машинного обучения для предсказания рыночной цены автомобиля 
на основе данных объявлений. В качестве алгоритма используется 
KNeighborsRegressor с подобранными гиперпараметрами.

## 📋 Задача

Предсказать рыночную цену автомобиля для продавцов, которые размещают 
объявления. Модель обучается на данных за предыдущий день, чтобы 
учитывать текущую ситуацию на рынке.

## 📊 Данные

- Источник: Karpov Course HardDA
- Период: объявления за 30 января 2023 года
- Целевая переменная: `log_price` (логарифм цены)
- Признаки: регион, марка, модель, год выпуска, тип пользователя

## 🔧 Пайплайн

1. **Предобработка категориальных признаков:**
   - `OneHotEncoder` — для столбцов с ≤ 5 уникальных значений
   - `TargetEncoder` — для столбцов с > 5 уникальных значений
2. **Масштабирование:** `StandardScaler`
3. **Модель:** `KNeighborsRegressor`

## 📈 Результаты

| Метрика | Кросс-валидация | Тест |
|---|---|---|
| R² | 0.72 | 0.73 |
| MAE | — | 0.37 |

**Лучшие гиперпараметры:**
- `n_neighbors`: 20
- `weights`: distance
- `p`: 1 (манхэттенское расстояние)
